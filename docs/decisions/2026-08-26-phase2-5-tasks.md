## Known environment issue

The remote-device bridge used to write files onto Jacob's Mac blocks file deletion
by default, which is incompatible with git operations that need to rewrite refs/lock
files (history rewrites, and apparently even some ordinary commits under contention).
Plain file writes work fine; anything requiring git to clean up after itself doesn't.
Repo-affecting git operations (rewrites, force-pushes) should go through Jacob's own
terminal, not the bridge, going forward.
